# Пакет ЛР 01

Початковий застосунок розташовано у starter-project/. Команди застосунку
виконуйте з цього каталогу. Незалежні приклади підготовки розташовано
в one-time-examples/; вони запускаються окремо й не додаються до застосунку.

Методичні рекомендації надано окремим DOCX. Архів не містить історії Git.
Для кроку git clone використовуйте адресу приватного студентського репозиторію,
надану викладачем. Якщо отримано лише цей ZIP, перед маршрутом клонування
імпортуйте вміст starter-project/ у свій порожній приватний репозиторій
за процедурою вашого університетського Git-сервера. Не імпортуйте каталог
прикладів у застосунок. Тег завершення v0.1.0 створюють після виконання ЛР 1.
