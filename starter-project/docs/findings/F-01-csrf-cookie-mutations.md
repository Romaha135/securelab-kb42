# F-01. Змінювальні маршрути з cookie не вимагають antiforgery-токена

**Статус:** ЗАПОВНИТИ (Fixed / Temporarily accepted)
**Актив:** стан інцидентів, сеанс користувача
**Компонент:** усі POST/PUT/DELETE з cookie-автентифікацією (таблиця периметра)
**Пріоритет:** ЗАПОВНИТИ (P1 / P2 / P3)

## Передумови і межі огляду
Commit ЗАПОВНИТИ; профіль; акаунти; reset-команда; маршрути; виключення.

## Вплив і ймовірність
**Статус перевірки:** ЗАПОВНИТИ (спостережено локально / оцінено за кодом)
ЗАПОВНИТИ. CVSS не вигадувати.

## Першопричина
На маршрутах немає перевірки, що запит зроблено свідомою дією нашого клієнта: браузер сам додає cookie, а інший порт localhost того ж site. SameSite=Lax і CORS цього не зупиняють.

## Виправлення
AddAntiforgery + /api/csrf-token + AntiforgeryFilter на кожному змінювальному маршруті, helper Client/csrf.js на сторінках. Commit ЗАПОВНИТИ.
